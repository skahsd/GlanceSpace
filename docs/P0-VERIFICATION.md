- P0 按项目标准不做硬链接去重、ADS、稀疏文件精确统计和 NTFS MFT。
- reparse point、云端占位条目、无权限及扫描中消失的项目会保留在树或列表中，并标记未知/部分/跳过状态。
- treemap 当前只绘制所在目录的直接子项，可逐层钻取；最多展示 5000 个子项，其余已知大小合并为“其他项目”。列表分页仍可访问全部子项；列表过滤不改变 treemap。
