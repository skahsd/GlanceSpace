# GlanceSpace P0 Implementation Plan

> Execution: superpowers:executing-plans, inline in this session. Existing approved specification: AGENTS.md and HANDOFF.md. No additional product approval is required for these implementation details.

**Goal:** Deliver the Windows x64 read-only analyzer with real scanning, progress controls, dual sizes, a browsable list and Canvas treemap.

**Architecture:** A single walkdir worker owns traversal, with shared Rust state for bounded queries. Channels carry throttled summaries; commands fetch children or the current visible tree. React renders controls and a Canvas treemap using d3-hierarchy coordinates. No AI, deletion, SQLite writes or full snapshot persistence.

**Tech Stack:** Tauri 2, Rust, walkdir, Windows file APIs, React, TypeScript, Vite, d3-hierarchy. Node's test runner for pure frontend logic; Rust tests use actual temporary files.

**Spec:** AGENTS.md (all P0 requirements) and HANDOFF.md sections 7, 9, 12.

## Global constraints

- Windows 10 22H2+ / Windows 11, x64, fixed local drives only, no elevation.
- Never follow reparse points or hydrate cloud files. Unknown/inaccessible sizes remain visible.
- No filesystem writes other than this application's own settings and test fixtures. No deletion commands.
- Rust retains the complete node table, no per-file IPC, no full tree transfer, no scan database writes.
- Existing documentation remains; work in the current workspace on codex/p0-analyzer.
